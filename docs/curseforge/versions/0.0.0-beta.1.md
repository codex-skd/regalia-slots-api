<h2>v0.0.0-beta.1 - Initial Release</h2>

<h3>Overview</h3>
<ul>
<li>Initial port of <strong>Regalia Slots API</strong> for NeoForge 26.2.0.45-beta / Minecraft 26.2, as an independent fork of <a href="https://www.curseforge.com/minecraft/mc-mods/curios">Curios API</a> by <strong>TheIllusiveC4</strong> (LGPL-3.0-or-later).</li>
<li>Full rebrand from the upstream project: new <code>mod_id</code>, Java package, and class names — no functional changes to the original slot/accessory system.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>mod_id</code>: <code>curios</code> → <code>regalia_slots_api</code>.</li>
<li>Java package: <code>top.theillusivec4.curios</code> → <code>com.skd.regaliaslotsapi</code>.</li>
<li>Assets/data namespace: <code>curios/</code> → <code>regalia_slots_api/</code>.</li>
</ul>

<blockquote>This is a beta release intended for early testing. Report issues on the <a href="https://gitlab.com/stalking-dragons/minecraft/regalia-slots-api/-/issues">GitLab issue tracker</a>.</blockquote>

<h2>v0.0.0-beta.1 - Port to Minecraft 1.21.1</h2>

<p>First beta of Regalia Slots API for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). Same accessory-slot API and same Curios compatibility layer as the 26.2 build &mdash; only the underlying platform differs.</p>

<h3>About this build</h3>
<ul>
<li><strong>Re-fork, not a back-port</strong>: rebuilt from the upstream <a href="https://www.curseforge.com/minecraft/mc-mods/curios">Curios API</a> 9.5.1+1.21.1 sources (TheIllusiveC4, LGPL-3.0), flattened from its multi-loader layout into a single NeoForge module, then rebranded to the Regalia Slots API identity.</li>
<li><strong>Curios compatibility layer</strong>: a verbatim copy of the Curios 1.21.1 API (<code>top.theillusivec4.curios.api.*</code>), a second logical <code>curios</code> mod id with the <code>curios:inventory</code> / <code>curios:item</code> capabilities, an <code>ICuriosPlatform</code> SPI adapter, and a first-login migration that carries equipped items over from a world that previously used the real Curios.</li>
<li><strong>11 preset slots</strong> (back, belt, body, bracelet, charm, curio, feet, hands, head, necklace, ring) granted to player-like entities by default.</li>
</ul>

<h3>Technical</h3>
<ul>
<li>Java 21 toolchain, mixin <code>compatibilityLevel</code> <code>JAVA_21</code>.</li>
<li>Package <code>top.theillusivec4.curios</code> &rarr; <code>com.skd.regaliaslotsapi</code>; mod id <code>curios</code> &rarr; <code>regalia_slots_api</code> across assets, data, lang, mixins, services and metadata. LGPL license headers and the on-disk NBT / datapack contracts kept verbatim.</li>
<li>JEI integration retained; EMI / REI kept as <code>compileOnly</code>.</li>
</ul>

<h3>Notes</h3>
<blockquote>Regalia Slots API is a library. It adds no content on its own &mdash; install it only as a dependency of another mod that requires it, on both client and server. <strong>Incompatible with the real Curios mod</strong> (shared <code>curios</code> mod id); install one or the other. LGPL-3.0-or-later; the full licence text ships in the jar.</blockquote>

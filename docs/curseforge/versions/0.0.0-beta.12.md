<h2>v0.0.0-beta.12 - Fix client load crash with mods that use the Curios screen</h2>

<p>Twelfth beta of Regalia Slots API for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). <strong>Fixes a client crash on load</strong> in any pack that combines Regalia with a mod referencing Curios' inventory screen (e.g. Apothic Attributes); affected users should update.</p>

<h3>Fixed</h3>
<ul>
<li><strong>Client crash during mod loading</strong> (<code>NoClassDefFoundError: top/theillusivec4/curios/client/gui/CuriosScreen</code>, from <code>EventBus.register</code> in <code>FMLClientSetupEvent</code> for <code>apothic_attributes</code>). Apothic Attributes registers a client Curios integration handler whenever <code>curios</code> is loaded, which Regalia's compatibility layer declares. Registering the handler resolves every parameter type on it, including <code>top.theillusivec4.curios.client.gui.CuriosScreen</code> — a class Regalia's bundled Curios mirror never carried. The missing class aborted the whole mod-loading phase.</li>
</ul>

<h3>Technical</h3>
<ul>
<li>Added <code>top.theillusivec4.curios.client.gui.CuriosScreen</code> as a load-only binary-compatibility shim (<code>abstract class … extends AbstractContainerScreen&lt;AbstractContainerMenu&gt; implements ICuriosScreen</code>). It is never instantiated and nothing in Regalia extends it; it exists only so reflection-driven type resolution at mod-loading time succeeds. The accessors third-party mods call (<code>getGuiLeft()</code>, <code>getGuiTop()</code>, <code>getMinecraft()</code>) resolve through the inherited NeoForge patches.</li>
<li><strong>Known limitation</strong> (no behaviour change, now documented): Regalia's real curios GUI does not extend this type, so a mod's <code>instanceof CuriosScreen</code> check on the live screen returns <code>false</code> and its curios-screen integration (such as Apothic Attributes' attribute-panel button) is skipped. It no longer crashes.</li>
</ul>

<h3>Notes</h3>
<blockquote>Regalia Slots API is a library. It adds no content on its own — install it only as a dependency of another mod that requires it, on both client and server. <strong>Incompatible with the real Curios mod</strong> (shared <code>curios</code> mod id); install one or the other. LGPL-3.0-or-later; the full licence text ships in the jar.</blockquote>

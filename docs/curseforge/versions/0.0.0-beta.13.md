<h2>v0.0.0-beta.13 - Third-party curios can be equipped again</h2>

<p>Thirteenth beta of Regalia Slots API for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). <strong>Fixes curio slots rejecting every item</strong> from every Curios-integrated mod; any pack using Regalia as its Curios replacement should update.</p>

<h3>Fixed</h3>
<ul>
<li><strong>No curio could be equipped into any slot, for any mod.</strong> The default slot validator <code>regalia_slots_api:tag</code> only accepted items in the <code>#regalia_slots_api:&lt;slotId&gt;</code> or <code>#regalia_slots_api:curio</code> item tags. Mods that ship Curios integration (Iron's Spellbooks, Reliquary, Relics, Jewelry, Equivalent Legacy, …) tag their wearables under the <code>curios:</code> namespace instead (<code>data/curios/tags/item/&lt;slotId&gt;.json</code>). Regalia already read those mods' <code>curios/slots</code> and <code>curios/entities</code> files, so the slots showed up in the GUI and were granted to the player — but every item was silently bounced back on drop because the validator's own tags were always empty.</li>
</ul>

<h3>Technical</h3>
<ul>
<li><code>RegaliaSlotsApiImplMixinHooks</code>: the built-in <code>regalia_slots_api:tag</code> predicate now also tests <code>#curios:&lt;slotId&gt;</code> and <code>#curios:curio</code>. The generic <code>curio</code>-slot fallback in <code>isStackValid</code> likewise now accepts item tags in the <code>curios</code> namespace, not just <code>regalia_slots_api</code>.</li>
<li>Brings the 1.21.1 branch in line with 26.2, where <code>RegaliaCompatMod#overrideTagPredicate</code> already widened the same predicate.</li>
</ul>

<h3>Notes</h3>
<blockquote>Regalia Slots API is a library. It adds no content on its own — install it only as a dependency of another mod that requires it, on both client and server. <strong>Incompatible with the real Curios mod</strong> (shared <code>curios</code> mod id); install one or the other. LGPL-3.0-or-later; the full licence text ships in the jar.</blockquote>

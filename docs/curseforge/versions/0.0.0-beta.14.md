<h2>v0.0.0-beta.14 - Spanish locale completion</h2>

<p>Translation-only beta for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>. No code changes.</p>

<h3>Fixed</h3>
<ul>
<li><strong>Spanish (<code>es_es</code>) locale</strong>: added the 12 keys that were present in
<code>en_us</code> but missing from <code>es_es</code> &mdash; the <code>/curios</code> command
feedback (<code>drop</code>, <code>dropAll</code>, <code>replace</code>), the entity-selector
argument description, the slot-count modifier tooltips
(<code>curios.modifiers.slots.plus/take[.multiple]</code>), the cosmetics toggle, the page counter
and the networking-failure message. Values come from the Mystical Realms Translation &amp; Fixes
resource-pack QA pass and now ship with the mod itself, so the overlay is no longer needed.</li>
</ul>

<h3>Notes</h3>
<blockquote>Library / API mod (Curios API fork), no gameplay change. Verified:
<code>./gradlew clean build</code> is green. Only
<code>assets/regalia_slots_api/lang/es_es.json</code> changed.</blockquote>

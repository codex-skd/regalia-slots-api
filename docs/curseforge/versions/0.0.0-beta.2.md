<h2>v0.0.0-beta.2 - Slot icon fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Missing-texture placeholder on empty slots</strong>: the 11 built-in slot definitions (ring, necklace, head, body, hands, feet, back, belt, bracelet, charm, curio) referenced their icon and validator under the old <code>curios:</code> namespace, which no longer exists after the rebrand. This made every empty accessory slot render as the purple/black missing-texture checker in the inventory GUI. Updated to <code>regalia_slots_api:</code>.</li>
</ul>

<blockquote>No API or gameplay behavior changes in this release — visual fix only.</blockquote>

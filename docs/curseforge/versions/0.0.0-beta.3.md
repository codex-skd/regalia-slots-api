<h2>v0.0.0-beta.3 - ResourceLocation Validation Fix</h2>

<p>Third beta of Regalia Slots API for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21).</p>

<h3>Fixed</h3>
<ul>
<li><strong>Crash on tooltip rendering</strong>: Fixed <code>ResourceLocation.assertValidPath</code> crash when viewing item tooltips with slot identifiers containing invalid ResourceLocation characters (uppercase, spaces, special characters). The "tag" curio predicate now validates slot identifiers before creating ResourceLocations.</li>
</ul>

<h3>Technical</h3>
<ul>
<li>Added <code>ResourceLocation.isValidPath(id)</code> check in <code>RegaliaSlotsApiImplMixinHooks</code> static initializer for the "tag" predicate to prevent invalid path exceptions from third-party slot type identifiers.</li>
</ul>

<h3>Notes</h3>
<blockquote>Regalia Slots API is a library. It adds no content on its own &mdash; install it only as a dependency of another mod that requires it, on both client and server. <strong>Incompatible with the real Curios mod</strong> (shared <code>curios</code> mod id); install one or the other. LGPL-3.0-or-later; the full licence text ships in the jar.</blockquote>

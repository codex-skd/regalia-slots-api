<h2>v0.0.0-beta.4 - Curios Compatibility Layer Fix</h2>

<p>Fourth beta of Regalia Slots API for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21).</p>

<h3>Fixed</h3>
<ul>
<li><strong>Third-party mod compatibility</strong>: Added missing internal mixin hook classes (<code>CuriosImplMixinHooks</code>, <code>CuriosUtilMixinHooks</code>) at <code>top.theillusivec4.curios.mixin.*</code>. Mods like <strong>Iron's Spellbooks</strong>, <strong>Sophisticated Backpacks</strong>, and other Curios-integrating mods that mix into Curios internals will no longer crash with <code>ClassNotFoundException: top.theillusivec4.curios.mixin.CuriosImplMixinHooks</code>.</li>
</ul>

<h3>Technical</h3>
<ul>
<li>New compat shim classes in <code>src/main/java/top/theillusivec4/curios/mixin/</code> delegating to the renamed <code>RegaliaSlotsApiImplMixinHooks</code> implementation.</li>
<li>Preserves binary compatibility with mods compiled against the real Curios API 1.21.1.</li>
</ul>

<h3>Notes</h3>
<blockquote>Regalia Slots API is a library. It adds no content on its own &mdash; install it only as a dependency of another mod that requires it, on both client and server. <strong>Incompatible with the real Curios mod</strong> (shared <code>curios</code> mod id); install one or the other. LGPL-3.0-or-later; the full licence text ships in the jar.</blockquote>

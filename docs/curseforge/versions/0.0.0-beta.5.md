<h2>v0.0.0-beta.5 - Entity slot tag references</h2>

<p>Fifth beta of Regalia Slots API for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21).</p>

<h3>Fixed</h3>
<ul>
<li><strong>Entity slot assignment via tags never worked</strong>: <code>data/&lt;mod&gt;/curios/entities/*.json</code> files using a tag reference in <code>"entities"</code> (e.g. <code>"#regalia_slots_api:player_like"</code>, the standard Curios pattern) crashed datapack loading with <code>ResourceLocationException: Non [a-z0-9_.-] character in namespace</code>. <code>RegaliaSlotsApiEntityManager.getSlotsForEntities</code> detected the leading <code>#</code> but passed the whole string to <code>ResourceLocation.parse</code>. It now strips the <code>#</code> before parsing the tag id, matching Curios.</li>
</ul>

<h3>Notes</h3>
<blockquote>Regalia Slots API is a library. It adds no content on its own &mdash; install it only as a dependency of another mod that requires it, on both client and server. <strong>Incompatible with the real Curios mod</strong> (shared <code>curios</code> mod id); install one or the other. LGPL-3.0-or-later; the full licence text ships in the jar.</blockquote>

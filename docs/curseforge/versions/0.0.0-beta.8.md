<h2>v0.0.0-beta.8 - Curios capability double-registration crash</h2>

<p>Eighth beta of Regalia Slots API for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21).</p>

<h3>Fixed</h3>
<ul>
<li><strong>Crash when a mod resolved the real <code>CuriosCapability</code> class</strong> (Create's goggles overlay, and any mod referencing <code>top.theillusivec4.curios.api.CuriosCapability</code>): <code>IllegalStateException: Attempted to register capability curios:inventory with existing type interface com.skd.regaliaslotsapi.api.type.capability.ICuriosItemHandler != interface top.theillusivec4.curios.api.type.capability.ICuriosItemHandler</code>. The compat entrypoint declared its own <code>curios:inventory</code> / <code>curios:item</code> capability objects typed against Regalia's interfaces, which collided with the identically-named ones in the copied Curios API the moment a third-party mod class-loaded that class. Only earlier crashes in the render path had been hiding it.</li>
</ul>

<h3>Technical</h3>
<ul>
<li><code>CuriosCompatMod</code> no longer creates its own <code>EntityCapability</code> / <code>ItemCapability</code> for the <code>curios</code> ids. It now registers its providers against the verbatim <code>CuriosCapability.INVENTORY</code> / <code>ITEM_HANDLER</code> / <code>ITEM</code>, so third-party mods resolve the exact same capability instances they expect.</li>
<li>Providers wrap Regalia's implementations in the beta.7 shims (<code>ShimCuriosItemHandler</code>, <code>ShimCurio</code>) so the returned objects implement the <code>top.theillusivec4.curios.*</code> interfaces; the <code>ITEM_HANDLER</code> provider returns the entity's equipped-curios <code>IItemHandler</code> view.</li>
</ul>

<h3>Notes</h3>
<blockquote>Regalia Slots API is a library. It adds no content on its own &mdash; install it only as a dependency of another mod that requires it, on both client and server. <strong>Incompatible with the real Curios mod</strong> (shared <code>curios</code> mod id); install one or the other. LGPL-3.0-or-later; the full licence text ships in the jar.</blockquote>

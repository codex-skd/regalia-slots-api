<h2>v1.0.0 - First stable release (Minecraft 1.21.1)</h2>

<p>First stable release of Regalia Slots API for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>
(Java 21). It consolidates the <code>0.0.0-beta.1</code> &rarr; <code>0.0.0-beta.15</code> line with
no further code changes. This build has been running in a full modded-server pack and is the
accessory-slot dependency for the team's other 1.21.1 mods.</p>

<h3>What the 1.21.1 line brought</h3>
<ul>
<li><strong>Re-fork from upstream Curios API 1.21.1</strong> (9.5.1+1.21.1), flattened from
multi-loader into a single NeoForge module and rebranded to the Regalia Slots API identity. 11
preset slots (back, belt, body, bracelet, charm, curio, feet, hands, head, necklace, ring) granted
to <code>player_like</code> entities by default.</li>
<li><strong>Bundled Curios API compatibility layer</strong>: a verbatim
<code>top.theillusivec4.curios.api</code> copy, a second logical <code>curios</code> mod id
registering the <code>curios:inventory</code> / <code>curios:item</code> capabilities, an
<code>ICuriosPlatform</code> SPI adapter, and first-login migration of items from a world that used
the real Curios. Over the beta line this layer was hardened against real third-party mods (Ars
Nouveau, Iron's Spellbooks, Supplementaries, L_Ender's Cataclysm, Create, Reliquary, Relics,
Apothic Attributes, Jewelry, Equivalent Legacy&hellip;), fixing a chain of load / tick / render
crashes and missing bridges.</li>
<li><strong>Curios-native advancements</strong>: the <code>equip_curio</code> trigger is also
registered under the <code>curios</code> namespace and its slot sub-predicate keyed on
<code>curios:slot</code>, so hard-coded <code>curios:equip_curio</code> criteria load and fire.</li>
<li><strong>Third-party slot validation</strong>: the default <code>regalia_slots_api:tag</code>
validator now also tests <code>#curios:&lt;slotId&gt;</code> / <code>#curios:curio</code>, so
wearables from any mod that ships Curios integration can be equipped.</li>
<li><strong>Third-party client renderers</strong>: models registered through Curios'
<code>CuriosRendererRegistry</code> (Relics, &hellip;) are bridged into the real render layer and
now show on the player model.</li>
<li><strong>Spanish (<code>es_es</code>) locale</strong> completed.</li>
</ul>

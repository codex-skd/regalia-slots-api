<h2>v1.1.0 - Legacy Curios data migration</h2>

<p>If you're switching an existing world from the real Curios mod to this one, your players' equipped items are no longer lost.</p>

<h3>Added</h3>
<ul>
<li>Automatic one-time migration of equipped items from a world previously played with the real Curios mod: on each player's first login after swapping the mod, whatever they had equipped is copied into the matching Regalia Slots API slot. Anything that no longer has a matching slot, or whose slot is already occupied, is returned to the player's regular inventory instead of being lost.</li>
</ul>

<blockquote>The real Curios mod jar must be removed from your <code>mods</code> folder before adding this one - both declare the mod id "curios" and NeoForge will refuse to load with both present.</blockquote>

<blockquote>Verified against a real save with actual Curios data before release: a Sophisticated Backpacks backpack, an Equivalent Legacy repair talisman and a Reliquary angelic feather were all recovered correctly into their matching slots.</blockquote>

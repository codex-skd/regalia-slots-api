# Regalia Slots API 1.1.1

## Fixes

- **Supersalto II (Jump Boost II) fix for Reliquary's `angelic_faher` item**: The effect was not applying consistently when the item was placed in the Amulet (necklace) slot. This was caused by the Curios compatibility layer not properly delegating `curioTick`, `onEquip`, `onUnequip`, `onStateChange`, `canEquip`, `canUnequip`, and other `ICurioItem` methods to the actual Curios API implementations from third-party mods.

The new `RegaliaCurioAdapter` in the compatibility layer now correctly bridges `top.theillusivec4.curios.api.type.capability.ICurioItem` → `com.skd.regaliaslotsapi.api.type.capability.ICurio`, ensuring active effects (like Jump Boost) work identically to the real Curios mod.

## Internal

- Renamed all compatibility layer classes from `Curios*` to `Regalia*` (e.g., `CuriosTypeBridge` → `RegaliaTypeBridge`, `CuriosCompatMod` → `RegaliaCompatMod`, etc.) for consistent naming within the Regalia Slots API codebase. The `top.theillusivec4.curios.api` package (copied Curios API for binary compatibility) remains unchanged.

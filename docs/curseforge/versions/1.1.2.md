<h2>v1.1.2 - Fix crash: Curios compatibility layer failed to load</h2>

<p>Version 1.1.1 renamed the Curios compatibility adapter classes from <code>Curios*</code> to <code>Regalia*</code> but did not update the five <code>META-INF/services/top.theillusivec4.curios.api.internal.services.*</code> files, which still pointed at the now non-existent <code>Curios*Adapter</code> classes.</p>

<p>On startup this made <code>CuriosServices</code> fail with <code>ServiceConfigurationError: ... Provider com.skd.regaliaslotsapi.compat.curios.CuriosCodecsAdapter not found</code>, aborting the mod's <code>RegisterEvent</code>. As a knock-on effect, other mods in the pack (Equivalent Legacy, Ascendant Equipment) failed to register their data components / items and the game reverted to a vanilla state instead of loading.</p>

<h3>Fixed</h3>
<ul>
<li>The five Curios <code>ServiceLoader</code> descriptor files now point at the correct classes: <code>RegaliaCodecsAdapter</code>, <code>RegaliaExtensionsAdapter</code>, <code>RegaliaNetworkAdapter</code>, <code>RegaliaRegistryAdapter</code>, <code>RegaliaSlotsAdapter</code>.</li>
</ul>
